# Инструкции Codex для проекта Log Analyzer

- Сначала прочитай `PROJECT_CONTEXT.md` и проверь фактическое состояние репозитория.
- Проект учебный, на Kotlin/JVM; цель — понять параллельное программирование и провести честные эксперименты.
- Пользователь хочет писать код сам: по умолчанию объясняй шаги, архитектуру и компромиссы; не реализуй целые модули без явного запроса.
- Предпочитай небольшие, проверяемые изменения и тесты; спрашивай перед крупным рефакторингом.
- Обязательно сохраняй эквивалентность последовательного и параллельного результатов.
- Следи за bounded queues/backpressure, завершением потоков, обработкой ошибок и памятью.
- Не заявляй о результатах бенчмарков без реальных измерений.
